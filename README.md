## 1. Tujuan Praktikum

Praktikum ini bertujuan untuk menerapkan:

- HTML5 semantik
- Accessibility Tree
- prinsip aksesibilitas web
- CSS Box Model
- CSS Flexbox
- CSS Grid
- responsive design
- mobile-first layout
- navigasi menggunakan keyboard
- skip-link
- pengujian menggunakan Lighthouse

Project dibuat menggunakan HTML5 dan CSS3 murni tanpa framework CSS eksternal.
